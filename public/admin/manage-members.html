วิธีเชื่อมต่อกับ SQL Server Management Studio (SSMS)

  1. ขั้นตอนที่ 1: รันไฟล์สร้างตารางในโปรแกรม SSMS

    เปิดโปรแกรม SQL Server Management Studio (SSMS) แล้วเปิดไฟล์ sql/buffet_loyalty_ssms.sql จากในโฟลเดอร์โปรเจกต์ กดปุ่ม Execute (F5) เพื่อสร้างฐานข้อมูล BuffetLoyaltyDB พร้อมทั้ง 4 ตาราง (PK/FK ครบ) และ SQL View

  2. ขั้นตอนที่ 2: ตั้งค่าเชื่อมต่อในไฟล์ .env 
    SQL_SERVER=localhost
SQL_PORT=1433
SQL_DATABASE=BuffetLoyaltyDB
SQL_USER=sa
SQL_PASSWORD=รหัสผ่านของคุณใน_SSMS
SQL_TRUST_SERVER_CERTIFICATE=true

    * หากใช้ SQL Server Express แบบมีชื่อ Instance สามารถใส่ SQL_SERVER=localhost\SQLEXPRESS ได้เลย (ท้ายไฟล์ .sql มีคำสั่งสร้าง User buffet_app เตรียมไว้ให้ด้วย)

  3. ขั้นตอนที่ 3: ทดสอบการเชื่อมต่อด้วยคำสั่งเดียว

    รันคำสั่ง npm run test:sql ใน Terminal เพื่อเช็กว่าเว็บคุยกับ SSMS สำเร็จ แล้วรีสตาร์ท npm start ป้ายสถานะด้านบนจะเปลี่ยนเป็นสีเขียวทันที!
